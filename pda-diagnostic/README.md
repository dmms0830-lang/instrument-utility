# PDA 진단 앱 (PM80 / PM85)

포인트모바일 **PM80**(Android 5.1~6.0), **PM85**(Android 8.1~9) 중고 구매 시
기기 성능·기능이 정상인지 현장에서 바로 점검할 수 있는 Android 앱입니다.
외부 라이브러리 없이 순수 Android API만 사용해 **minSdk 16**(Android 4.1)부터 동작하므로
PM80/PM85보다 오래된 4.x대 PDA에도 설치할 수 있습니다.

## 테스트 항목 (15종)

| 항목 | 확인 내용 |
|---|---|
| 기기 정보 | 모델/시리얼/RAM/저장소가 판매 스펙과 일치하는지 |
| 디스플레이 | 단색·그라데이션·체크무늬 순환으로 불량화소/번인/얼룩 |
| 터치스크린 | 격자 칠하기로 데드존, 멀티터치 지점 수 |
| 물리 버튼 | 키코드 감지 (트리거/볼륨/기능키/키패드) |
| 바코드 스캐너 | 웨지·인텐트 모드 모두 자동 감지, 스캔 횟수 기록 |
| 배터리 | 잔량/전압/온도/건강 상태/충전 인식 (중고 핵심 체크) |
| Wi-Fi | 연결 신호세기(RSSI)/링크속도 + 주변 AP 스캔 |
| 블루투스 | 어댑터 상태 + 주변 기기 검색 |
| GPS | 위성 수신 개수, 첫 위치 획득 시간(TTFF) |
| 카메라 | 미리보기/초점/플래시/전·후면 전환 |
| 스피커/마이크 | 저음·고음 톤 재생, 5초 녹음 후 재생 |
| 진동 | 짧게/길게/패턴 |
| 센서 | 가속도·자이로·조도·근접 등 실시간 값 |
| NFC | 태그 인식 (옵션 사양) |
| 성능 벤치마크 | CPU 정수/실수, 메모리, 저장소 속도 — 기기 간 상대 비교 |

각 항목을 테스트한 뒤 **정상/불량**을 판정하면 메인 화면에 기록되고,
**리포트 공유** 버튼으로 전체 결과를 텍스트로 내보낼 수 있습니다
(판매자에게 이의 제기할 때 증빙으로 활용).

## APK 받기

GitHub Actions가 push마다 자동으로 APK를 빌드합니다.

- **Releases** 페이지의 `pda-diagnostic-latest` 릴리스에서 APK 다운로드 (고정 링크)
- 또는 Actions 탭 → 최신 `Build PDA Diagnostic APK` 실행 → Artifacts

## 설치 방법

1. APK 파일을 PDA에 복사 (USB, 웹 다운로드, SD카드 등)
2. PDA에서 **설정 → 보안 → 출처를 알 수 없는 앱(알 수 없는 소스) 허용** 체크
3. 파일 관리자에서 APK 실행 → 설치
4. 첫 실행 시 카메라/마이크/위치 권한을 **허용**

ADB 사용 시:
```bash
adb install pda-diagnostic.apk
```

## 바코드 스캐너 테스트 참고

Point Mobile 기기는 기본적으로 **키보드 웨지 모드**(스캔값이 키 입력으로 들어옴)라서
앱의 입력창에 커서를 두고 트리거를 당기면 바로 잡힙니다.
인텐트 모드로 설정된 기기도 `device.scanner.USERMSG` 등 주요 브로드캐스트를 수신합니다.
아무 반응이 없으면 기기의 **ScanSetting(스캐너 설정)** 앱에서 스캐너가
활성화되어 있는지 먼저 확인하세요.

## 중고 구매 시 앱 외 육안 체크리스트

- 스캔창(스캐너 유리) 스크래치 — 판독률에 직접 영향
- 배터리 부풀음(스웰링), 접점 부식
- 충전 크래들/USB 포트 핀 상태
- 화면 모서리 파손, 터치 들뜸
- 뒷면 라벨 시리얼과 기기 정보 화면 시리얼 일치 여부
- PM80: 키패드 인쇄 마모 정도 (사용량 가늠)

## 빌드 (개발자용)

```bash
cd pda-diagnostic
gradle assembleRelease   # 또는 Android Studio에서 열기
# 결과물: app/build/outputs/apk/release/app-release.apk
```

> `app/pda-diag.keystore`는 진단 앱 서명 전용 공개 키스토어입니다(비밀 아님).
> 일관된 서명으로 재설치 없이 업데이트하기 위한 용도입니다.
